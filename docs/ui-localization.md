# UI 多语言资源

支持英文、简体中文、繁体中文；首次跟随系统，未知语言回退英文。语言配置使用稳定键 `app_language`，沿用 Android SharedPreferences、JVM settings.properties、iOS/macOS UserDefaults，不使用数据库存储。

## 文案入口

- 共享文案维护在 `shared/resources/src/commonMain/composeResources/values`、`values-zh`、`values-zh-rTW`，按功能分文件。
- 独立 `:shared:resources` 提供官方 `Res.string`、`Res.plurals` 和资源资产，包名为 `top.iwesley.lyn.music.resources`；引用资源的模块显式依赖它。图片继续保存在 `player/app`，混用时导入图片 `Res as PlayerRes`。
- Android 共享文案由官方任务打包为资源资产，不另生成 Android XML。原生控件在生命周期协程中调用官方资源读取 API，Compose 页面使用官方 composable 读取 API。
- 原生 macOS 小播放器使用三套 `Localizable.strings`；SwiftUI 通过指定 Bundle 解析文案，Kotlin 桥接复用系统语言匹配规则。
- `ProvideUiLanguage` 订阅现有语言版本流；仅 `UiResourceEnvironment.kt` 隔离 Compose 1.11.1 的内部资源环境接口，保留主题与密度，只替换语言和地区。切换不修改进程 Locale，不使用 `key(language)`，不重建业务组件或页面树。升级资源库时需专项验证该文件。

新增文案时，使用可读的小写英文和下划线键名，同时补齐三种语言。键名描述功能、对象和用途，例如 `common_close`、`cast_proxy_port_unavailable`；禁止哈希、随机串、无意义编号和机械截取整句文案。不同用途通过业务含义区分，不靠摘要消除重名。资源检查脚本会检查疑似摘要的键名分段，并排除 `decade`、`facade` 等已知正常英文词；这属于启发式检查，可读性仍须人工审查。正常英文词的排除规则维护在 `tools/ui_resource_keys.py`，不得用随机字母串扩大排除范围。本次 1,054 项重命名的一对一记录见 [键名对照表](ui-string-key-renames.tsv)，旧键只作为审计记录保留，不提供运行时别名。

完整句子使用位置参数模板 `%1$s`；数量使用 `plurals` 的 `one`、`other`。有多个数量的句子使用完整外层模板，嵌套数量资源，避免拼接句子片段。

业务层保存 `UiText.StringRef`、`PluralRef`、`Raw` 或 `Joined`，例如 `uiText(Res.string.common_close)` 和 `uiPlural(Res.plurals.common_track_count, count, count)`；UI 的 `displayText()` / `uiString(...)` 是 `@Composable`。数量始终明确传入，不从格式参数推断。消息保留到显示时再解析。已存在的提示可以随语言切换。第三方错误和服务端内容通过 `UiText.Raw` 保留；应用生成的可见平台错误使用带资源描述的异常，新诊断 message 使用可读资源键和原始参数，异常创建不读取资源；显式诊断、第三方详情与历史记录保持原文，并在 UI 解析描述。不要根据中文原文动态匹配翻译，也不要用翻译后的显示文字判断业务状态。

歌单、来源名称和服务器地址等业务校验使用 `requireUi` / `checkUi` 或带资源描述的异常。汇总来源错误时保留嵌套 `UiText`，避免把描述提前转换为异常的诊断 message。

远程喜欢同步按来源汇总 `UiText`，优先读取异常原因链中的资源描述；用户来源名与普通错误详情保持原文。喜欢更新遇到不可用来源时也使用资源异常。歌单文本导入的失败行通过可选 `messageText` 保存描述，由报告界面解析；原始 `message`、行号、导入文本和旧报告保持兼容。

投屏状态用 `messageText` / `errorText` 保存描述，由 UI 解析 `castSessionStatusText`。JNI 应用错误返回 `lyn_ui:` 加稳定资源键；适配器只识别约定标识，不匹配中文原文，未知详情保留原值。设备名称不参与翻译，发现设备数使用复数资源。

TV 的 DLNA 接收侧也使用稳定 JNI 错误标识。接收端启动结果通过 `UiText` 进入 Router 状态，诊断字符串和界面描述分开保存；清除错误时同时清理两者。系统播放器错误保持原始详情，没有详情时使用当前语言的播放失败说明。

WebDAV 的操作标识使用 `WebDavOperation`，认证、HTTP 状态和本地根目录错误携带资源描述。Android/JVM 的异常适配器保留 `IOException` 类型和原始原因，服务端详情保持原文；诊断入口输出资源键与原始参数，不读取资源。Android 封面文件和所选封面的读取失败也通过资源描述进入标签编辑提示。

Android 播放错误沿异常原因链读取 `UiTextFailure`，保留 Media3 封装前的应用描述；诊断链单独保存，重试和切歌时同步清理两种错误字段。无文案标识的第三方错误保留原始诊断详情，循环异常链不会阻止发布错误。共享播放加载入口也保留被封装的文案标识。

Samba 来源路径校验、来源不可用及播放位置越界使用资源描述；打开、读取和大小探测用 `SambaOperation` 标识操作。Android/JVM 的 Samba IO 适配器保留原始异常类型要求和 cause，应用说明与服务端详情、路径分开存储，语言切换时只解析说明。

桌面图片、字体、VLC、音乐文件夹及数据位置选择器在每次打开时按当前语言解析应用提供的标题和过滤器说明。数据位置的目标目录、空间、当前目录及待处理操作校验通过 `requireUi` / `checkUi` 保留异常类型和资源描述；字体加载失败也保留资源描述。迁移过程的底层诊断和历史记录详情保持原值。

播放队列、播放次数、来源概要、下载进度和 TV 搜索等数量句使用复数资源；数量位于第几个格式参数与单复数选择无关，非首位数量显式传给 `uiPlural`。文件夹概要分别选择歌曲数和子目录数的复数项。桌面歌词关闭按钮的 tooltip 和无障碍说明在语言变化时异步解析；同步 getter 只返回已解析快照，不读取资源，不重建窗口。

播放 Gateway、Repository 和 Snapshot 使用 `errorText` 传递应用错误；`errorMessage` 保留诊断字符串。界面通过 `playbackErrorText` 优先解析描述，只有没有描述的外部错误才使用原始详情。成功播放、切歌和清除错误时同步清理描述；Toast 按描述去重，不按翻译后的文字去重。

Apple 播放入口保留本地访问异常中的 `UiTextFailure`，不支持的媒体定位符同时携带资源描述和诊断字符串。AVPlayer 的系统错误详情保持原文，缺少详情时使用当前语言的播放失败提示。离线下载的空文件、写入失败和 XML 响应使用资源描述；服务端消息、状态及错误代码保留原值，地址回退仍按原异常类型判断。

歌词类型枚举保存类型化资源引用；歌词确认对象只保存候选结果，界面文案在读取时解析。连续切换语言不需要重新搜索或重建候选结果。搜索结果、确认提示和分享候选的行数使用完整外层模板嵌套复数资源，覆盖 0/1/2 行。

内置歌词来源通过 `LyricsSearchCandidate.sourceNameText` 保存资源描述，搜索列表、共享及 TV 确认框和分享候选在显示时解析；原始 `sourceName` 与用户保存的来源名不变。新扫描的不支持格式失败通过 `ImportScanFailure.reasonText` 保存资源描述，`reason` 继续保留诊断原文；这两个字段不写入数据库。

启动迁移错误页优先读取异常链中的 `UiTextFailure`；启动清理及安全警告以 `UiText` 贯通到共享应用，已关闭的警告不因切换语言重新出现。配置字段、路径及未资源化的底层诊断作为原始详情保留。VLC 目录选择、本地目录缺失与 VLC 媒体启动失败使用资源异常，不改变目录操作、播放重试或加载策略。

Navidrome、Subsonic 与 Emby 的应用生成请求、HTTP 及响应校验说明使用资源描述；服务端消息和第三方异常保持原文。Navidrome 原生 API 不兼容异常仍保留独立类型，用于原有导入回退。Workflow JSON 校验与手动应用失败使用资源描述，字段名、原始值与来源名称作为参数保留，JSON 库诊断不翻译。“我的”页面最近播放同步失败直接传递已有资源，避免重复外层说明。

内网/外网地址回退优先读取异常链中的 HTTP 状态和请求失败类型，不使用资源键、格式参数或翻译后的文字分类。HTTP 401/403 不重试备用地址，408 和 5xx 可以重试；凭据及地址校验失败不重试。第三方异常及明确保留的旧诊断继续兼容原有判断，循环原因链不会阻塞分类。异常仍保留原有 IllegalArgumentException/IllegalStateException 分类及原因。

语言偏好写入失败通过设置消息展示三语言说明及原始详情，不写回旧选择或重置表单；选择继续由偏好流更新，取消异常继续传播。

扫描错误、扫描警告和离线下载错误在写入原有 `lastError` / `errorMessage` 字段前，捕获一次当前有效语言，通过官方资源 API 解析为完整文字。数据库只保存普通字符串，不保存资源键、参数或版本化描述；表结构、数据库版本和历史数据不变。读取时直接显示已保存的原文，后续切换语言不重新翻译历史错误，也不重复扫描或下载。普通第三方详情保持原文；资源读取失败时，警告保留原始说明，应用错误使用固定英文通用说明，不将诊断资源键写入数据库。成功扫描或下载继续清空错误；即时 UI 提示仍通过 `UiText` 延迟解析。

Android 桌面歌词在 Service 生命周期内订阅有效语言版本，只重绘最新快照并刷新关闭按钮的无障碍描述。语言刷新不调用歌词获取，不重建窗口，不清除位置或控制状态；Service 销毁后取消订阅。iOS Samba 测试的 Files 建议和 Android Samba 投屏的来源不可用校验也使用资源异常，沿用现有 Toast 通道。

iOS 扫描中已枚举文件失效或提供方离线时，通过资源异常和 `reasonText` 传递说明；系统错误保留原始详情。歌词分享字体规范化使用 `copy` 保留内置字体的 `displayNameText`，按钮、菜单及索引按当前语言解析；用户导入字体名称不翻译，语言变化不重新加载字体或生成分享内容。

Android 歌词分享字体尚未加载时，按钮复用核心层的 10 种内置字体键映射，优先于缓存名称；其他平台真实字体名称保持原值。TV 详情传递原始标题和可选 `subtitleTrackCount`，显示时解析空标题占位符与歌曲数复数；旧参数的原始副标题保持兼容。JVM WebDAV 大小探测失败携带资源描述并保留原有英文诊断与 `IOException` 类型；Android WebDAV 定位失败复用同一跳过函数，使用携带字节位置资源的 `EOFException` 子类。

iOS 标签读取结果通过 `tagLabelText` 保存“只读”格式描述，并传递到标签行缓存；界面在显示时解析描述。原始格式名称和用户编辑草稿保持原值，不增加数据库字段。

Android 主应用、TV 和车机在 Application 配置变化时刷新系统语言；TV 也在恢复前台时刷新。更新只调用 `AppLanguageRuntime.updateSystemLanguage`，不重建播放器或应用组件，也不覆盖手动语言选择。

运行时的语言选择、系统语言标签、设置存储引用和有效语言版本保存在同一个原子状态中；系统刷新只更新标签。选择流和有效语言流同步读取该状态，不另设可变缓存。Compose Provider 订阅语言版本，当前语言映射为 en、zh-CN、zh-TW。非 Compose 入口通过 `observeResolvedUiText` 订阅文本描述和语言版本，固定一次解析的环境，取消过期任务并阻止过期结果回写。原生事件队列延迟更新控件时，在实际回写前再次调用解析结果的 `isCurrent` 检查，覆盖语言变化和文本描述变化。原生控件更新原有文字；macOS 桥接只向 Swift 提供普通 `errorMessage` 快照，并合并最新播放状态。有效语言不变时不增加版本，重新安装设置存储时保留版本序列。手动选择串行完成配置保存与运行时更新；设置页面从语言流订阅结果，不在保存返回后写回旧选择。

设备信息缓存保存原始 CPU 描述和 `logicalCoreCount`。共享设置与 TV 设置在显示时解析 `cpuDescriptionText`，核数使用复数资源；切换语言无需重新读取硬件信息。缺失的系统版本也由 UI 生成当前语言的占位符。

普通和流式扫描报告通过单个 `warnings: List<ImportScanWarning>` 传递警告；每条警告的 `diagnostic` 保留原始说明，可选 `text` 保存多语言描述。新增、删除、调整顺序及报告转换时，两份信息随同一个对象传递；`warningUiText()` 优先取描述，缺省使用原文。Navidrome、Subsonic、Emby 空曲库提示以及 iOS Samba/WebDAV 能力说明复用已有资源。两种扫描保存入口在原有 `lastError` 字段中保存当时语言的完整文字，重新读取后保持原文；纯原始警告和旧记录不翻译，空列表或原始说明全部为空白时清空字段。资源解析失败时整组回退为原始说明，取消异常继续传播，不保存资源键、不迁移数据库。Android/JVM 扫描失败共用纯逻辑构造，优先提取资源异常链，原始 `reason` 不变。在线歌曲缺少远端 song id 的喜欢及加入歌单操作使用资源异常，校验顺序不变。

iOS 应用声明 `en`、`zh-Hans`、`zh-Hant` 三种支持语言，Xcode `knownRegions` 同步维护，开发语言继续使用英文；应用内语言选择仍由现有偏好控制。权限说明保留原值，没有新增 `InfoPlist.strings`。

系统通知、媒体浏览服务、权限说明、日志、协议、数据库标识、歌曲、歌词、用户输入和已保存名称不属于此次适配范围。系统字体名称和音乐元数据保持原值；未知信息的占位符在显示层处理。`你好 Hello` 是固定字体字形覆盖样本。

## 校验

```sh
python3 tools/check_ui_localization.py
python3 -m unittest discover -s tools -p 'test_ui_resource_keys.py'
./gradlew :shared:resources:jvmTest --tests top.iwesley.lyn.music.resources.OfficialResourceCatalogTest
# 其他本地测试使用 --tests 限定直接受影响的类，避免运行全量测试。
./gradlew :composeApp:assembleDebug :tvApp:assembleDebug :automotiveApp:assembleDebug
```

静态脚本检查三种语言的键、资源类型、位置参数及复数项，并检查指定 UI 文件中的残留中文硬编码。明确保留的诊断不计入 UI 文案。官方生成器负责类型化访问器；静态检查与参数测试负责格式参数签名。

逻辑测试覆盖系统语言匹配、无效配置、连续切换、系统刷新与手动选择并发、配置保存延迟、语言流订阅、原始详情、0/1/2 数量、多个数量、JVM 配置读写，以及播放状态与设置表单保留。布局通过代码静态审查确认换行、截断和滚动配置；没有运行真机、模拟器、UI 测试或界面抽查。
